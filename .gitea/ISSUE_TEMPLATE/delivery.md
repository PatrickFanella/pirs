## Outcome

What result should this issue deliver?

## Scope

What is included, and what is deferred?

## Acceptance criteria

- [ ] Describe an observable result and how it will be accepted.

## Verification

Name the commands, environment, or evidence needed. Link retained evidence
when it matches the accepted revision. Separate implementation, qualification,
deployment, and release decisions.

## Dependencies and owner decisions

Link prerequisites and identify who can resolve each missing decision.
Write "None" when there are no prerequisites.

## Planning

Choose an owner and an existing outcome milestone when applicable. After
triage, add selected current work to the organization Active delivery board.
Keep future roadmap work in the repository. A due date is an agreed commitment.

## Boundaries

Record consent, deployment, data, and recovery boundaries that apply to this
work. Keep credentials and private evidence out of the issue.
